AssetFare Capabilities Tool

A read-only smolagents agent tool.

smolagentstoolread-onlycross-chain

This Space hosts an agent tool (tool.py), meant to be loaded by an agent — not run as a web app. It fetches and strictly validates the AssetFare v2 public capability/status surface (https://api.assetfare.dev): the supported chains, the 9 (chain, token) endpoints, the 72 directed routes, and the USD amount bounds. It confirms the surface it reads is quote-only and that the server never signs or submits for these endpoints, failing closed otherwise.

Load it in an agent (review tool.py first): 
from smolagents import load_tool

caps = load_tool(
    "odaiin/assetfare-capabilities",
    trust_remote_code=True,           # runs the reviewed tool code in your process
    revision="2770263d157006d5e4dfd90a42fa0713c3de5ec6",  # reviewed immutable release
)
print(caps())  # dict of chains, endpoints, route counts, amount bounds

Takes no inputs. Does not execute, bridge, swap, sign, or move funds. Use it to check which cross-chain corridors can be quoted before requesting a quote with odaiin/assetfare-quote. Review the source and tests and the AssetFare agent integration guide.
