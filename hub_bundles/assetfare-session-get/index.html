AssetFare Session Get Tool

A non-custodial smolagents agent tool — read-only /v2/session/{id}.

smolagentstoolnon-custodialcross-chain

This Space hosts an agent tool (tool.py), meant to be loaded by an agent — not run as a web app. Read-only GET /v2/session/{session_id} for a caller-owned AssetFare session (fixed origin https://api.assetfare.dev). Returns the session's current workflow state and current unsigned action. Requires the caller-owned session capability token (sent only in the X-AssetFare-Session-Token header) and the session_id. It never signs, submits, or moves funds; the returned 'server_signs_or_submits' is al AssetFare never signs or submits; this tool never receives a private key and fails closed on any response that claims the server will sign or submit.

Load it in an agent (review tool.py first): 
from smolagents import load_tool

tool = load_tool(
    "odaiin/assetfare-session-get",
    trust_remote_code=True,           # runs the reviewed tool code in your process
    revision="cf03a26155aba8804aa38c1a4ed7c2c410fe9d1a",  # reviewed immutable Space revision
)

Tool name: assetfare_session_get. Does not execute, bridge, swap, sign, or move funds — any transfer is a separate caller wallet action taken after explicit approval. Review the source and tests and the AssetFare agent integration guide.
