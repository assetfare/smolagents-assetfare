AssetFare Prepare Tool

A non-custodial smolagents agent tool — explicit caller-approved one-shot /v2/prepare (unsigned bundle).

smolagentstoolnon-custodialcross-chain

This Space hosts an agent tool (tool.py), meant to be loaded by an agent — not run as a web app. Explicit caller-approved, non-custodial one-shot POST /v2/prepare for an AssetFare route whose fresh quote reports current availability (fixed origin https://api.assetfare.dev). Before calling it, compare fresh AssetFare and competitor quotes at the actual intended amount; USD 1 is smoke-only, USD 50 is merely the lowest observed native-USDC winning bucket, and USD 1,000 is a representative exampl AssetFare never signs or submits; this tool never receives a private key and fails closed on any response that claims the server will sign or submit.

Load it in an agent (review tool.py first): 
from smolagents import load_tool

tool = load_tool(
    "odaiin/assetfare-prepare",
    trust_remote_code=True,           # runs the reviewed tool code in your process
    revision="9c71dd6b1aa51484237d17d69090b599baf8fe3c",  # reviewed immutable Space revision
)

Tool name: assetfare_prepare. Does not execute, bridge, swap, sign, or move funds — any transfer is a separate caller wallet action taken after explicit approval. Review the source and tests and the AssetFare agent integration guide.
