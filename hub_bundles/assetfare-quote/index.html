AssetFare Quote Tool

A non-custodial smolagents agent tool — read-only, quote-only cross-chain quote.

smolagentstoolnon-custodialcross-chain

This Space hosts an agent tool (tool.py), meant to be loaded by an agent — not run as a web app. Read-only quote client for one cross-chain corridor via the AssetFare v2 API (fixed origin https://api.assetfare.dev). This tool's entire scope is to fetch and validate a single conversion quote and return it; it is not the AssetFare service and does not itself prepare, sign or submit. It covers 6 source chains (solana, base, arbitrum, robinhood, polygon, optimism), 11 (chain, token) source endpoi AssetFare never signs or submits; this tool never receives a private key and fails closed on any response that claims the server will sign or submit.

Validated route transparency: every quote returns an ordered direct_route_summary with named protocols, normalized endpoints, base-unit amounts, and the exact 1bp fee step. route_aggregator_used=false means AssetFare did not call a market-wide aggregator API. Across external_intent routes may internally source or aggregate destination liquidity; that provider behavior is disclosed separately. Every response also validates the complete continuation_v3 and returns only a sanitized, unranked, expiring continuation_descriptor. Raw claims, bounds, and action handoffs are suppressed; this tool never creates approval, selects a mode, collects wallets, or calls prepare/session.
Load it in an agent (review tool.py first): 
from smolagents import load_tool

tool = load_tool(
    "odaiin/assetfare-quote",
    trust_remote_code=True,           # runs the reviewed tool code in your process
    revision="c65ab5604c2f8e04e0d344b98d85d3ceaf9e78fb",  # reviewed immutable Space revision
)

Tool name: assetfare_quote. Does not execute, bridge, swap, sign, or move funds — any transfer is a separate caller wallet action taken after explicit approval. Review the source and tests and the AssetFare agent integration guide.
