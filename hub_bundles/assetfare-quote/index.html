AssetFare Quote Tool

A read-only, quote-only smolagents agent tool.

smolagentstoolread-onlycross-chain

This Space hosts an agent tool (tool.py), meant to be loaded by an agent — not run as a web app. It fetches and strictly validates one non-custodial cross-chain conversion quote from the AssetFare v2 API (https://api.assetfare.dev). It never authenticates a wallet, opens a session, prepares an unsigned action, signs, or submits, and it fails closed if a response claims the server will sign or submit.

Load it in an agent (review tool.py first): 
from smolagents import load_tool

quote = load_tool(
    "odaiin/assetfare-quote",
    trust_remote_code=True,           # runs the reviewed tool code in your process
    revision="<reviewed commit SHA>",  # pin the exact commit you audited
)
result = quote(
    from_chain="solana", from_token="SOL",
    to_chain="base",     to_token="ETH",
    amount_usd=250,
)

Surface: 4 chains (solana, base, arbitrum, robinhood), 9 (chain, token) endpoints, 72 directed routes, USD 1–1000. Does not execute, bridge, swap, sign, or move funds — acting on a quote is a separate wallet action taken outside this tool. See README.md and PRIVACY.md in this repo.
